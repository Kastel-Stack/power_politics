# Kastel Futures — Power Politics Research

This repository contains research frameworks and working papers for the **Kastel Futures / Multipolar Red Queen (MRQ)** programme.

## Start here

- [The Eight Axes of Power](./Kastel_Futures_Axes_of_Power.md) — diagnostic framework for power, resources, networks, framing, influence, deployment, institutions and opportunity.
- [Attractor C research](./research/attractor-c/README.md) — source-grounded working overview of the model-mediated society, Western security-industrial coordination, platform economic power, the computational ontology, behavioural/cognitive alignment, hyperreality and recursive self-modelling.

## Interpretation standard

Distinguish **documented developments**, **supported causal mechanisms**, **testable hypotheses**, and **normative proposals**. The MRQ/Attractor concepts are research models; they should not be presented as established predictions or evidence of unified state–corporate intent.

Related but separate: [Kastel Stack](https://github.com/Kastel-Stack/kastel-stack) is the adaptive-business operating-system project; [Kastel World](https://github.com/Kastel-Stack/kastel-world) is the speculative story-to-real-world bridge.
